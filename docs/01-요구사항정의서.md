# 01. 요구사항 정의서 (SRS)

| 항목 | 내용 |
|---|---|
| 문서 버전 | 1.0 (기준 릴리즈 `planner-v43`, 커밋 `e524719`) |
| 작성 기준 | 저장소 코드(`index.html`, `sw.js`, `supabase/schema.sql`), 커밋 이력, 개발 중 사용자 피드백 기록 |
| 상태 표기 | **구현** = 배포됨 · **보류** = 계획만 있음 · **폐기** = 만들었다가 제거 또는 시도 후 거절 · **대체** = 다른 방식으로 바뀜 |

## 1. 목적 · 범위 · 용어

### 1.1 목적
아이폰 세로 화면에서 **반복 강의 시간표와 단발성 약속을 한 시간 축 위에** 보여 주고, 설치형 앱처럼 오프라인에서도 동작하며, 선택적으로 폰 ↔ PC 간 동기화를 제공하는 개인용 플래너를 만든다.

### 1.2 범위

| 포함 | 제외 |
|---|---|
| 시간표(N일/주/하루) · 주간 목록 보기 | 월간 달력 보기 (주간 목록의 미니 달력은 주 선택용) |
| 일정 CRUD, 반복 일정(요일·기간) | 반복 일정의 개별 회차 수정 ("이 날만") |
| 카테고리 CRUD · 필터 | 다른 사용자와 일정 공유 |
| 한국 공휴일 자동 표시 | 외부 캘린더(Google/iCloud) 가져오기·내보내기 |
| 백업 파일 내보내기 · 복원 | 알림(Web Push) |
| 이메일 계정 · 동기화 (Supabase) | 소셜 로그인, MFA, 회원 탈퇴 |

### 1.3 용어

| 용어 | 정의 |
|---|---|
| 반복 일정 (`lecture`) | 매주 지정 요일에 반복되는 일정. 선택적으로 반복 시작일(`from`)·종료일(`until`) |
| 특정 날짜 일정 (`appointment`) | 한 날짜(`date`)에만 있는 일정 |
| 카테고리 (태그) | 일정 분류. 이름·색·이모지. 일정의 `cat` 필드로 연결 |
| N일 보기 | 기준일(`winStart`)부터 N일(4 또는 5) + 오른쪽 끝에 다음 날 흐린 미리보기 칸 |
| 묶음 카드 (cluster) | 시간이 겹치는 일정들을 한 카드로 합쳐 개수 배지와 함께 표시 |
| 로컬 우선 (local-first) | 모든 변경은 기기에 먼저 저장, 서버는 나중에 맞춤 |
| Tombstone | 삭제된 항목을 지우지 않고 `deleted=true`로 남겨 다른 기기에도 삭제를 전파 |
| LWW (Last-Write-Wins) | 같은 항목을 두 곳에서 고치면 **수정 시각(`updated_at`)이 더 나중인 쪽**이 남음 |
| OTP | 메일로 받은 6자리 인증번호 (가입 확인 · 비밀번호 찾기) |
| Owner | 이 기기 일정의 주인 계정 uid (`weekly-planner-owner`) |

## 2. 이해관계자 · 페르소나

|---|---|---|

### 페르소나

| 항목 | 내용 |
|---|---|
| 이름 | "산업보안학과 3학년 학생" |
| 기기 | 아이폰 (홈 화면 앱으로 설치), 학교·집 PC (Chrome/Edge) |
| 패턴 | 학기 시간표(매주 반복) + 스터디·약속(단발) + 공휴일 확인 |

| 원하는 것 | "오늘부터 4일"이 바로 보이기, 폰에서 고친 게 PC에서도 보이기 |
